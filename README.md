## About the Project
This project is created to explore the fundemental implementation of the decision tree  algorithm in phython, bridging the gap between theoritical concepts and pratical application. By the pratical implementations we are able to understand the step by step implementation of Decision Tree using sklearn library


## Features

* Feature 1: Implementation of label encoder to encode the catergorical data 
* Feature 2: Implementation of decisiom tree classifier
* Feature 3: Implementation of accuracy score
